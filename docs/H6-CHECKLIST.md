## 2. 验收标准 11 — 真机扫码识别

**准备工作：** Mac 上打开 `test-barcodes.html`（项目根目录），或者把文件 AirDrop 到手机用 Safari 打开。

1. 容器 → 牛奶冰柜 → 点一个格子 → 「上架到 X 格」
2. 点「扫描条码」→ 相机对准屏幕上的**鲜牛奶条码**（`6901028075831`）
3. 确认填回来的条码是 `6901028075831`（**13 位，不是 12 位，开头不是 6901 少了什么**）
4. 填日期 + 天数 → 保存

- ✅ 期望：1–2 秒内自动识别并关闭相机页
- ❌ 扫不出 → 把手机拿远一点（15–20 cm）、屏幕亮度拉满、别开 Live Text 干扰
- ❌ 权限弹窗没出现 → 设置 → 隐私与安全性 → 相机 → LastCall 打开

**顺带验前导零（标准 8）：** 手输 `0012345678905`，保存后去看格位弹窗 —— 末四位应显示 `8905`，说明整串没被数值化。
