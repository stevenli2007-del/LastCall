## 2. 各阶段详细定义

### H0 — 打通签名链路（0.5h）🔴 熔断关

**目标：** 一个新创建的空白 SwiftUI App，能通过 USB 跑到你手机上、图标出现在桌面、点开能显示 Hello World。

**步骤：**
1. Xcode → File → New → Project → iOS → App
   - Product Name: `LastCall`
   - Interface: **SwiftUI**
   - Language: **Swift**
   - Storage: **SwiftData**（勾上）← 这会让 Xcode 自动生成 ModelContainer 样板，省一步
   - ⚠️ 不要勾 "Include Tests"
2. 左侧**最顶上的蓝色项目图标** → **Signing & Capabilities** 标签
3. **Team 下拉框** → 选 `<你的名字> (Personal Team)`
4. 勾 **Automatically manage signing**
5. 黄字警告应该全部消失
6. USB 连手机 → 顶部设备选择器选你的 iPhone → **⌘R**

**完成的定义（缺一不可）：**
- [ ] Xcode 无红色错误
- [ ] 手机桌面上出现了 App 图标
- [ ] 点开能运行，不是闪退
- [ ] 手机上首次打开若提示「未受信任的企业级开发者」→ 设置 → 通用 → VPN与设备管理 → 信任

**这一步一旦卡住超过 45 分钟 → 立刻触发 §5 熔断决策。不要在证书上死磕。**

**完成的定义：**

### H2 — 容器创建 + 格子网格（2h）

**产出：** `ContainerViews.swift`
- 创建容器表单（名称 / 冰柜·货架 / rows / cols / depthCapacity，默认 3×2×5）
- 容器 Tile 列表（填充进度条）
- 容器详情：正视图 `rows × cols` 的 `LazyVGrid`，只画格子不画纵深
- 格子里用**小色块**展示纵深件数（沿用原型 `.unit` 的视觉），标注 `A1 A2 A3…`
- 每行格子数严格等于 `columns`，行数严格等于 `rows`
- 格位弹窗：列出该格内所有件（位置码、名称、条码后四位、日期、状态徽章）
- 从首页临期项跳转时能聚焦并高亮目标格子

**完成的定义：**
- [ ] PRD 验收标准 1：3×2×5 → 正视图恰 6 格 A–F
- [ ] PRD 验收标准 7：点提醒 → 进对容器 + 高亮格子 + 显示位置码
